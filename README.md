# HTTP-Auditor
Scanner CLI interactif pour auditer les en-têtes de sécurité HTTP d'un serveur (CSP, HSTS, X-Frame...). Évalue les vulnérabilités via un score de risque visuel en ASCII. Conçu pour les audits défensifs (Blue Team).
